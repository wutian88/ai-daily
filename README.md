# AI每日研习（独立项目）

与 ai-english-pronunciation 为并列项目，不再放入英语站内部。

目标网址：https://wutian88.github.io/ai-daily/ （需独立仓库部署成功后才能使用）。

## 日报口径

- 每天UTC01:00（北京09:00目标时间），GitHub可能延迟；可手动workflow_dispatch。不需要个人电脑开机。
- 固定关注7个项目，加GitHub搜索近30天新建、带artificial-intelligence主题的累计星数前23项，去重后上限30。这个主题搜索不是覆盖所有AI项目，搜索结果只标“新项目热度”。
- public/ai-daily/snapshots.json 格式为仓库→日期→星数，保留含当天在内最近45个日历日；候选仓库变化可能使部分仓库历史中断。
- 周星数增长只用今天减精确7天前；无起止快照就标“增速数据积累中（已有N天）”，不拿累计星数替代。负增长如实显示。
- 每周日附周榜，每月1日附月榜；月榜用上月1日至本月1日，仅从快照读取。缺数据输出占位，不猜排名。日报正文保持2—4条，榜单为单独汇总条目。
- 博客按发布时间；论文按订阅源发表/公告日期和主题匹配，预印本效果只属作者报告，不排热度。自动短摘要可能为英文，不是每日模型深度解读。

## 运行与验证

python -m unittest discover -s scripts/tests -p 'test_*.py'

python scripts/cloud_daily.py

标准库，无需付费模型密钥。验证后同一提交保存日报、快照、归档和状态；采集失败使用上一版已提交内容部署。此独立工作流不新增故障演练job或保护层。本机旧定时已暂停。

## 手机

部署后iPhone Safari打开独立网址，分享→添加到主屏幕。手机实际显示需用户确认。老网址待迁移完成后保留跳转。

首个真实7天星数增长最早在第8个日期快照采集后可用；周榜是否有足够数据取决于星期日及起止日期是否采到，不承诺首次周日即有真实排名。
